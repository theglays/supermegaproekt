# Три карты: по следам Германна

Интерактивная point-and-click игра по мотивам повести А. С. Пушкина «Пиковая дама», созданная на движке Unity.

![Unity](https://img.shields.io/badge/Unity-2022.3_LTS-black?logo=unity)
![C#](https://img.shields.io/badge/C%23-10+-purple?logo=csharp)


---

## О проекте

**«Три карты»** — это образовательная игра в жанре narrative point-and-click, которая позволяет игроку исследовать художественное пространство повести Пушкина через интерактивные механики, диалоговую систему и динамический журнал расследования.

Игрок оказывается в роли Германна и проходит путь от карточной ночи в квартире офицеров до двора графини, собирая улики, разгадывая тайны и погружаясь в атмосферу Петербурга XIX века.

### Цель проекта
Популяризация русской классической литературы через интерактивную цифровую визуализацию. Мы верим, что классика оживает, когда читатель становится исследователем.

---

## Особенности

- **🏛 Атмосферные локации в стиле пушкинской эпохи** — художественная визуализация интерьеров и дворов Петербурга XIX века по мотивам повести
- **🔍 Point-and-click исследование** — кликайте по объектам, находите улики, продвигайте сюжет
- ** Диалоговая система** — разговаривайте с персонажами, узнавайте их мотивы
- **📖 Динамический журнал** — автоматическое ведение дневника и досье персонажей
- **🎨 Гибридная графика 2.5D** — 3D-окружение + 2D-спрайты персонажей в изометрии
- **💾 Система сохранений** — автосохранение прогресса между сессиями

## 🎮 Геймплей и управление

### Управление
| Действие | Клавиша / Мышь | Описание |
|----------|----------------|----------|
| **Перемещение** | `ЛКМ` (Левая кнопка мыши) | Клик по полу. Персонаж строит путь через NavMesh. |
| **Взаимодействие** | Клавиша `E` | Нажимается при появлении визуальной подсказки над объектом/NPC. |
| **Отмена / Назад** | `ПКМ` или `Esc` | Закрыть окно диалога, журнал или меню. |
| **Открыть журнал** | `TAB` | Переключение между вкладками «Дневник» и «Досье». |
| **Меню паузы** | `Esc` | Остановить игру, открыть настройки или выйти в главное меню. |

### Игровой цикл
1. **Исследуйте** локацию, кликая по полу для перемещения.
2. **Взаимодействуйте** с объектами и персонажами, нажимая `E` при подсказке.
3. **Читайте** диалоги и описания, собирайте информацию.
4. **Заполняйте журнал** — записи разблокируются автоматически.
5. **Продвигайтесь** по сюжету, выполняя задания квест-трекера.

## 🛠 Установка и запуск

Поскольку проект находится в активной разработке, готовый `.exe` файл пока не собран. Вы можете запустить игру напрямую из редактора Unity через **GitHub Desktop** (без командной строки).

### Системные требования
* **ОС:** Windows 10/11 (x64) или macOS
* **Процессор:** Intel Core i5 / AMD Ryzen 5
* **Оперативная память:** 8 GB RAM
* **Видеокарта:** NVIDIA GTX 1050 / AMD RX 560 или встроенная графика
* **Место на диске:** ~2 GB
* **Обязательно:** Unity Hub + редактор **Unity 2022.3 LTS**

---

###  Пошаговая инструкция через GitHub Desktop

#### Шаг 1. Установка GitHub Desktop
1. Перейдите на официальный сайт: [https://desktop.github.com](https://desktop.github.com)
2. Нажмите кнопку **Download for Windows** (или **Download for macOS**).
3. Запустите скачанный установщик и следуйте инструкциям.
4. После установки откройте GitHub Desktop и войдите в свой GitHub-аккаунт (если есть). Если аккаунта нет — нажмите **Skip this step** (пропустить), это не обязательно.

#### Шаг 2. Клонирование репозитория
1. В GitHub Desktop нажмите **File** → **Clone repository...** (или используйте горячую клавишу `Ctrl + Shift + O`).
2. В открывшемся окне перейдите на вкладку **URL**.
3. Вставьте ссылку на репозиторий: https://github.com/theglays/supermegaproekt
4. 4. В поле **Local path** выберите папку, куда будет скачан проект (например, `C:\Projects\three-cards`).
5. Нажмите **Clone**.
6. Дождитесь завершения загрузки (внизу появится прогресс-бар).

#### Шаг 3. Открытие проекта в Unity
1. Откройте **Unity Hub**.
2. Нажмите кнопку **Add** (Добавить) в правом верхнем углу.
3. В открывшемся окне найдите папку, куда вы клонировали проект (например, `C:\Projects\three-cards`), и выберите её.
4. Unity Hub распознает проект и добавит его в список.
5. Нажмите на проект в списке — откроется Unity Editor.
6. Дождитесь импорта проекта и компиляции скриптов (индикатор прогресса появится в правом нижнем углу). Это может занять 2–5 минут при первом запуске.

#### Шаг 4. Запуск игры
1. В окне **Project** (обычно внизу экрана) перейдите в папку `Assets` → `Scenes`.
2. Дважды кликните по сцене `MainMenu` (или `Prologue`, если главного меню ещё нет).
3. Нажмите кнопку **Play** (▶) в верхней панели Unity.
4. Игра запустится в режиме редактора.

> **Важно:**
> - Убедитесь, что вы используете именно **Unity 2022.3 LTS**. Открытие проекта в более старых или новых мажорных версиях (например, 2021 или 2023) может привести к ошибкам совместимости.
> - Если при запуске вы видите розовые текстуры, подождите пару минут — Unity компилирует шейдеры.
> - Если возникает ошибка `Library not found`, закройте Unity, удалите папку `Library` в проекте (если она есть) и откройте проект заново.

### Обновление проекта (если вы уже клонировали его ранее)

Если вы уже скачали проект, но хотите получить последние изменения:

1. Откройте **GitHub Desktop**.
2. Выберите репозиторий `three-cards` в списке слева.
3. Нажмите кнопку **Fetch origin** (или **Pull**) в верхней панели.
4. Дождитесь завершения синхронизации.
5. Откройте проект в Unity — изменения подтянутся автоматически.

## Архитектура и стек

Проект построен по **слоистой архитектуре (Layered Architecture)** для обеспечения модульности и масштабируемости:

* **Presentation Layer:** Unity UI (Canvas, TextMeshPro), обработка ввода (ЛКМ, клавиша `E`), изометрическая камера (`Orthographic`, X:30°/Y:45°).
* **Logic Layer:** Менеджеры (`InteractionManager`, `DialogueManager`, `JournalManager`, `GameStateManager`, `SaveSystem`). Общаются через шину событий.
* **Data Layer:** `ScriptableObjects` (хранение текстов и конфигов), `JSON` / `PlayerPrefs` (локальные сохранения), ассеты (3D-модели, 2D-спрайты).

**Технологический стек:**
* **Движок:** Unity 2022.3 LTS, C# 10+
* **Навигация:** NavMesh, Raycast
* **Версионирование:** Git + GitHub (ветвление `feature/*`, Git LFS для ассетов)
* **Контент:** Blender (3D), Adobe Creative Cloud (2D/UI), Visual Studio (IDE)
